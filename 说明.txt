SkyReaver 桌面宠物助手（零安装版）
=================================

一、这是什么
桌面小助手，Q版神兽 / 少女两种形象。
- 按字母键：角色的手移动到对应按键
- 没按键时：手悬空待机
- 按空格：手移到空格键
- 闲置超过 10 秒：自动变回兽态，离开键盘绕圈走
- 吃饱后 60 分钟会饿，饿了弹出红色“我要吃饭！”
- 右键宠物：投喂文件夹 / 立即吃饱 / 退出
- 窗口置顶、透明背景、鼠标穿透，只显示角色

二、零安装版（推荐）—— 怎么打开
Windows 系统自带 PowerShell，本版不需要装任何软件。
1. 把本文件夹解压出来，不要只双击 zip 里面的文件
2. 双击【启动桌宠.bat】
3. 桌面右上角就会出现宠物，开始互动

首次运行注意：
- 如果 Windows 弹出安全提示，选“仍要运行”
- 如果跳出红色报错文字，请把截图发给我，我帮你改
- 这是用 PowerShell 重写的版本，我没有办法替你实测过，
  个别细节（手跟键位、输入法识别）可能需要微调，报错随时发我

四、怎么互动（没有屏幕按钮，全是自动 + 右键）
- 按键盘字母：手跟着按到对应键
- 超过 10 秒不碰键盘：变回兽态、离开键盘绕圈
- 饿了（吃饱后 60 分钟）：自动弹红字“我要吃饭！”
- 右键点宠物：弹出菜单
    · 投喂文件夹…   → 选一个文件夹让宠物吃掉，饥饿重置
    · 立即吃饱（测试）→ 立刻重置饥饿
    · 退出          → 关闭宠物

五、想要 exe（双击的独立程序，不用 PowerShell 框）
- 方式B（需本机装一次 Python）：双击“打包.bat”生成 exe
- 方式C（本机零安装）：用 GitHub 云端自动编译，见 .github 配置，
  上传到 GitHub → Actions → Run workflow → 下载 exe

六、可调参数（改 桌宠助手.ps1 顶部“配置”区）
- 闲置多久绕圈：$IDLE_SECONDS（默认10秒）
- 多久会饿：$HUNGRY_SECONDS（默认 60*60 秒）
- 手移动快慢：$SMOOTH
- 绕圈范围/速度：$WALK_MIN_X/Y、$WALK_MAX_X/Y、$WALK_SPEED
- 窗口屏幕位置：$form.Location 的 (120,150)
- 键位不准：改 $script:keyPos 里的坐标

七、注意
- 仅支持 Windows（依赖 Windows 输入法 / 键盘钩子）
- 首次运行如有安全软件提示，是正常现象，允许即可
